开发环境配置

1.1 JDK 25

下载 JDK 25，并选择与系统、处理器架构匹配的安装包。

下载 Eclipse Temurin JDK 25

常见 Windows 电脑选 x64，Apple Silicon Mac 选 aarch64。安装后执行以下命令，确认主版本均为 25。

java -version
javac -version

版本不一致时检查 PATH 和 JAVA_HOME；JAVA_HOME 应指向 JDK 根目录。

1.2 IntelliJ IDEA

从 JetBrains 官网下载 IntelliJ IDEA

打开模板项目，将 Project SDK 和 Gradle JVM 设为 JDK 25。

中文
文件 → 项目结构 → 项目 → SDK → JDK 25
EN
File → Project Structure → Project → SDK → JDK 25
中文
设置 → 构建、执行、部署 → 构建工具 → Gradle → Gradle JVM → JDK 25
EN
Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JVM → JDK 25

1.3 Fabric Mod Template

打开 Fabric 官方模板生成器

选择 Minecraft 26.3，填写模组名称、Mod ID 和包名。示例：Vocabulary Spark / vocabulary-spark / io.github.piscescup.vocabularyspark。

按需启用客户端源码分离和数据生成。解压后，用 IDEA 打开项目根目录，等待 Gradle 同步完成。

在项目根目录执行对应系统的命令：

# Windows PowerShell
.\gradlew.bat runClient

# macOS / Linux
./gradlew runClient

客户端正常启动即完成验证。失败时查看 Build 或终端报错。

项目文件

Gradle

文件或目录用途
build.gradle声明 Loom、Minecraft 和 Fabric 依赖，以及编译、资源处理规则。26.3 模板使用 net.fabricmc.fabric-loom。
gradle.properties保存版本与项目属性：minecraft_version、loader_version、fabric_api_version、version、group。
settings.gradle定义项目名称、插件解析仓库等设置。
gradle/wrapper/gradle-wrapper.properties指定 Gradle 版本，使用项目自带 Wrapper 即可。
gradlew / gradlew.batWrapper 启动脚本：macOS / Linux 使用 gradlew，Windows 使用 gradlew.bat。
.gradle/ · build/本地缓存与构建输出，不作为源码提交。

Fabric

位置用途
src/main/java/通用 Java 代码和 ModInitializer 入口，不放客户端专用类。
src/client/java/启用源码分离时的客户端代码，包含 ClientModInitializer。
src/main/resources/fabric.mod.json声明 id、name、version、environment、entrypoints、depends、mixins。
assets/vocabulary-spark/resources 下的客户端资源目录，命名空间与 Mod ID 一致。
data/vocabulary-spark/配方、战利品表等服务端数据，按需创建。
*.mixins.jsonMixin 配置；客户端配置可位于 src/client/resources。
src/main/generated/启用数据生成后的输出目录；修改生成器后重新生成。

Mod ID 可用 vocabulary-spark；Java 包名不能包含连字符。

构建验证

# Windows PowerShell
.\gradlew.bat build

# macOS / Linux
./gradlew build

产物位于 build/libs，注意区分模组 JAR 与 sources JAR。

我的习惯

我将 Mod ID、元数据、日志和工具方法集中放在 References 类中，便于维护。

References 示例

按项目补充 package 声明，并保持 Mod ID 与 fabric.mod.json 一致。

VocabularySparkModReferences.java
import com.google.gson.Gson;
import com.google.gson.GsonBuilder;
import net.fabricmc.loader.api.FabricLoader;
import net.fabricmc.loader.api.ModContainer;
import net.fabricmc.loader.api.metadata.ModMetadata;
import net.minecraft.resources.Identifier;
import org.apache.logging.log4j.LogManager;
import org.apache.logging.log4j.Logger;
import org.jetbrains.annotations.Contract;
import org.jspecify.annotations.NonNull;

/**
 * Constants
 *
 * @author REN YuanTong
 * @since 1.0.0
 */
public final class VocabularySparkModReferences {

    private VocabularySparkModReferences() {
    }

    /** The mod identifier, also used as the namespace for mod resources. */
    public static final String MOD_ID = "vocabulary-spark";

    /** The Fabric loader instance providing access to registered mods. */
    public static final FabricLoader FABRIC_LOADER = FabricLoader.getInstance();

    /** The registered container for the mod identified by {@link #MOD_ID}. */
    public static final ModContainer VOCABULARY_SPARK_MOD = FABRIC_LOADER
            .getModContainer(MOD_ID)
            .orElseThrow();

    /** The metadata supplied by {@link #VOCABULARY_SPARK_MOD}. */
    public static final ModMetadata VOCABULARY_SPARK_METADATA = VOCABULARY_SPARK_MOD
            .getMetadata();

    /** The human-readable mod name obtained from the registered metadata. */
    public static final String MOD_NAME = VOCABULARY_SPARK_METADATA
            .getName();

    /** The friendly version string obtained from the registered metadata. */
    public static final String MOD_VERSION = VOCABULARY_SPARK_METADATA
            .getVersion()
            .getFriendlyString();

    /**
     * The shared Gson instance for JSON serialization and deserialization.
     * Uses pretty printing and disables HTML character escaping in JSON output.
     */
    public static final Gson GSON = new GsonBuilder()
            .setPrettyPrinting()
            .disableHtmlEscaping()
            .create();

    /** The shared Log4j logger named using {@link #MOD_NAME}. */
    public static final Logger MOD_LOGGER = LogManager.getLogger(MOD_NAME);

    /**
     * Creates a resource identifier using {@link #MOD_ID} as its namespace.
     * For example, {@code "textures/gui/dictionary.png"} produces
     * {@code "vocabulary-spark:textures/gui/dictionary.png"}.
     *
     * <p>The path is passed unchanged to
     * {@link Identifier#fromNamespaceAndPath(String, String)}. It must contain
     * only lowercase ASCII letters, digits, slashes, periods, underscores or
     * hyphens; a namespace prefix must not be included.
     *
     * @param path the non-null resource path within the mod's namespace
     * @return a new identifier with the mod namespace and the supplied path
     * @throws NullPointerException if {@code path} is null
     * @throws net.minecraft.IdentifierException if {@code path} contains an
     *         invalid resource-path character
     * @see Identifier#fromNamespaceAndPath(String, String)
     */
    @NonNull
    @Contract("_ -> new")
    public static Identifier fromPath(String path) {
        return Identifier.fromNamespaceAndPath(MOD_ID, path);
    }
}

字段与方法

字段或方法用途
MOD_ID模组标识与资源命名空间。
FABRIC_LOADERFabric Loader 实例。
VOCABULARY_SPARK_MOD按 Mod ID 查找容器；不存在时 orElseThrow() 抛出异常。
VOCABULARY_SPARK_METADATA模组元数据，提供名称与版本。
GSON共享 JSON 工具，启用格式化输出并关闭 HTML 字符转义。
MOD_LOGGERLog4j 日志器，注意导入对应的 Logger 类型。
fromPath(path)为资源路径补上本模组命名空间，参数不带命名空间前缀。

创建贴图资源标识的示例：

Identifier texture = VocabularySparkModReferences
        .fromPath("textures/gui/dictionary.png");
// vocabulary-spark:textures/gui/dictionary.png

静态初始化

调用 fromPath() 也会初始化元数据字段，因此需在 Fabric 已加载模组信息后使用。MOD_ID 是编译期常量，单独读取通常不触发初始化。

注解

@NonNull 来自 JSpecify，表示非空返回类型；@Contract 来自 JetBrains，"_ -> new" 表示正常返回新对象。两者用于静态分析，不执行运行时判空。

版本适配

MC 26.3 使用 net.minecraft.resources.Identifier。此示例采用 Log4j，官方模板使用 SLF4J，注意区分 Logger 导入。
