项目简介主要功能使用说明
Minecraft 模组 · Carpet GUI

01 / OVERVIEW

项目简介

Carpet GUI 把 Carpet 及其附属模组的规则浏览、编辑和配置管理集中到一个游戏内界面里。你可以按名称或描述搜索规则，把相关规则放进文件夹式的规则组，先查看当前值与目标值的差异再应用，也可以导出为 JSON 与他人分享。单人游戏和联机服务器都能使用。

02 / FEATURES

主要功能

01

查找与编辑

支持按规则 ID、名称和描述搜索（包含中英文翻译），并用开关、选项列表或输入框直接修改规则。

02

规则组与提交记录

把相关规则整理成规则组，暂存数值后创建带说明的本地提交，随时查看每次提交的差异。

03

预设与应用预览

可以把已提交的值导出为 JSON，并导入到其他工作区；应用前会对比当前值与目标值，并说明无法应用某条规则的原因。

03 / GET STARTED

使用说明

  1. 01

    安装依赖

    安装 Fabric Loader、Fabric API、Carpet 与 TCDCommons，建议同时安装 Mod Menu。

  2. 02

    放入对应版本

    选择与 Minecraft 版本匹配的 Carpet GUI。若要在服务器上修改规则，服务器也需要安装相关的 Carpet 模组。

  3. 03

    打开规则界面

    进入世界后打开 Carpet GUI，就可以浏览规则、整理规则组，并按需应用或导出。
