Minecraft 模组 · More Advancements

01 / OVERVIEW

项目简介

More Advancements 为 Minecraft 新增多种主题进度与挑战目标，覆盖维度探索及日常活动等内容，并提供完整的中文与英文进度文本。

02 / FEATURES

主要功能

01

主题进度

生成的进度数据按冒险、末地、农牧业、Minecraft 与下界分类组织。

02

挑战目标

现有挑战包括收集头颅、使用望远镜观察生物及食用紫颂果。

03

中英文支持

仓库包含 zh_cn 与 en_us 的进度标题和描述。

03 / GET STARTED

使用说明

  1. 01

    了解模组说明

    查看仓库 README，了解模组支持的 Minecraft 版本、Fabric 依赖及进度扩展规划。

  2. 02

    浏览进度列表

    查看生成的进度数据与中英文语言文件，预览各主题下的挑战条件与文本描述。

  3. 03

    提交进度建议

    如果你有新的进度创意或发现文本问题，欢迎通过 GitHub Issues 提交建议。
