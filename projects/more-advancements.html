01 / OVERVIEW

项目简介

More Advancements 为 Minecraft 增加额外进度与趣味目标。从探索不同维度到完成日常行动，这个项目为游戏提供了更多可以尝试的挑战，并包含中文和英文文本。

02 / FEATURES

主要功能

01

主题进度

生成的进度数据按冒险、末地、农牧业、Minecraft 与下界分类组织。

02

趣味目标

现有目标包括收集头颅、用望远镜观察生物，以及食用紫颂果。

03

中英文显示

仓库包含 zh_cn 与 en_us 的进度标题和描述。

03 / GET STARTED

开始使用

  1. 了解项目
    先阅读 README，了解项目增加进度挑战的目标。
  2. 浏览进度数据
    查看生成的进度数据，并结合语言文件了解每个目标的标题与描述。
  3. 分享新的目标
    如果你有新的进度想法，可以按照 README 的建议，通过 GitHub Issues 提交。
