01 / OVERVIEW

项目简介

More Advancements 为 Minecraft 增加额外进度与挑战目标，覆盖维度探索及日常活动等内容，并提供中文与英文进度文本。

02 / FEATURES

主要功能

01

主题进度

生成的进度数据按冒险、末地、农牧业、Minecraft 与下界分类组织。

02

挑战目标

现有挑战包括收集头颅、使用望远镜观察生物及食用紫颂果。

03

中英文支持

仓库包含 zh_cn 与 en_us 的进度标题和描述。

03 / GET STARTED

开始使用

  1. 查阅项目说明
    查阅 README，了解项目的进度扩展目标与相关说明。
  2. 浏览进度数据
    查阅生成的进度数据及对应语言文件，了解各项挑战的标题与描述。
  3. 提交进度建议
    如需提出新增进度建议，可依据 README 说明，通过 GitHub Issues 提交。
