Minecraft 模组 · TeamCraft

01 / OVERVIEW

项目简介

TeamCraft 是用于快速创建和管理 Minecraft 队伍的 Fabric 模组。你可以在图形界面或通过命令选择玩家、配置队伍规则、设置队伍名称与颜色、控制友军伤害，并自动完成分队。联机时，服务器和所有客户端都需要安装 TeamCraft。

02 / FEATURES

主要功能

01

灵活分队

可以按每队人数或固定的队伍数量分队，并选择按列表顺序或随机分配。

02

自定义队伍

自定义队伍名称和颜色轮换，还能查看自己的队伍，浏览、编辑或解散已有队伍。

03

界面与命令

图形界面和命令都能完成配置，每条命令还可以单独设置权限等级。

03 / COMMANDS

命令示例

/teamcraft init @a
/teamcraft config players-per-team 2
/teamcraft config mode random
/teamcraft config friendlyfire false
/teamcraft build-teams

04 / GET STARTED

使用说明

  1. 01

    安装模组

    安装 Fabric Loader，并将匹配版本的 Fabric API 与 TeamCraft 放入游戏或服务器的 mods 文件夹。联机时服务器和客户端都要安装。

  2. 02

    打开界面或输入命令

    进入世界后按 Backspace 打开 TeamCraft（也可以在 Mod Menu 中打开配置），或直接输入上方的示例命令。

  3. 03

    创建队伍

    添加候选玩家并选择分队规则，点击「应用」保存设置，或点击「保存并分队」立即建队。
