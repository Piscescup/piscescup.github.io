01 / OVERVIEW

项目简介

PiscesCup Easy 是面向 Minecraft 玩家管理的 Fabric 模组，通过统一命令提供白名单管理、管理员（OP）权限管理、封禁管理及语言设置功能。根据 README 说明，推荐在服务端使用。

02 / FEATURES

主要功能

01

白名单管理

支持按玩家名称添加或移除白名单成员，管理服务器访问权限。

02

权限与封禁

提供管理员（OP）权限与玩家名称封禁名单管理功能，统一处理常见管理操作。

03

语言设置

支持查询当前语言设置，并切换中文或英文命令反馈。

03 / GET STARTED

开始使用

  1. 阅读使用说明
    查阅 README 中的适用环境与命令说明，确认所选构建与使用的 Minecraft 版本兼容。
  2. 管理白名单
    在具备相应管理权限的环境中执行下方命令，并将 TestPlayer 替换为实际玩家名称。
  3. 选择反馈语言
    使用语言设置命令选择 zh_cn 或 en_us。

README 命令示例

/pc_easy whitelist add TestPlayer
/pc_easy setting lang set zh_cn
