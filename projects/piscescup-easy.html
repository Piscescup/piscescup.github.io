01 / OVERVIEW

项目简介

PiscesCup Easy 是一个简化 Minecraft 玩家管理的 Fabric 模组。它把白名单、OP、封禁名单和语言设置放在统一命令下，README 推荐在服务端使用。

02 / FEATURES

主要功能

01

白名单管理

根据玩家名添加或移除白名单成员，方便管理服务器访问。

02

权限与封禁

管理 OP 与玩家名称封禁名单，集中处理常见管理操作。

03

语言设置

查询当前语言，并在中文与英文命令反馈之间切换。

03 / GET STARTED

开始使用

  1. 阅读使用说明
    先查看 README 中的适用环境与命令说明，确认所用构建与你的 Minecraft 版本匹配。
  2. 管理白名单
    在具有相应管理权限的环境中使用下方命令，并把 TestPlayer 替换为实际玩家名。
  3. 选择反馈语言
    使用语言设置命令选择 zh_cn 或 en_us。

README 命令示例

/pc_easy whitelist add TestPlayer
/pc_easy setting lang set zh_cn
