Minecraft 模组 · Pisces Cup Easy

01 / OVERVIEW

项目简介

Pisces Cup Easy 是一款面向 Minecraft 的 Fabric 玩家管理模组，通过统一命令提供白名单、管理员（OP）权限、封禁名单及反馈语言设置等功能，推荐安装于服务端。

02 / FEATURES

主要功能

01

白名单管理

支持按玩家名称添加或移除白名单成员，管理服务器访问权限。

02

权限与封禁

提供管理员（OP）权限与玩家名称封禁名单管理功能，统一处理常见管理操作。

03

语言设置

支持查询当前语言设置，并切换中文或英文命令反馈。

03 / COMMANDS

玩家管理命令示例

/pc_easy whitelist add TestPlayer
/pc_easy setting lang set zh_cn

04 / GET STARTED

使用说明

  1. 01

    阅读使用说明

    查阅 README 中的运行环境要求与完整命令说明，确认所选版本与当前 Minecraft 版本兼容。

  2. 02

    管理白名单

    在具备相应管理权限的环境中执行上方示例命令，并将 TestPlayer 替换为实际玩家名称。

  3. 03

    选择反馈语言

    使用语言设置命令切换反馈语言，支持 zh_cn（中文）与 en_us（英文）。
