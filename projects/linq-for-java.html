01 / OVERVIEW

项目简介

LINQ for Java 基于 Enumerable 模型，为 Java 集合与序列提供查询操作。通过 where、select、orderBy 等方法组合数据处理步骤，多种中间操作采用延迟执行机制，在遍历或消费结果时执行。

02 / ENUMERABLE FAMILY

序列类型

提供对象序列及 int、long、double 基本类型专用序列，可根据数据类型选择相应查询入口。

Enumerable<T>

对象序列

从数组、集合或可变参数创建序列，使用筛选、排序、分组和连接等通用操作。

IntEnumerable

Int 序列

通过 Linq.ofInts 创建 int 专用序列，支持数值查询与 sum、average 等聚合操作。

LongEnumerable

Long 序列

通过 Linq.ofLongs 处理 long 数据，在基本类型管道中减少不必要的装箱与拆箱。

DoubleEnumerable

Double 序列

通过 Linq.ofDoubles 查询 double 数据，适合浮点数筛选、转换与统计。

03 / QUERY OPERATORS

主要功能

01

筛选与投影

通过 where 筛选元素、select 转换结果，并使用 skip 与 take 控制序列范围。

02

排序与分组

通过 orderBy 与 thenBy 实现多级排序，使用 groupBy 按键对元素分组。

03

连接与集合

通过 join 与 groupJoin 关联序列，使用 distinct、union、intersect 与 except 执行去重及集合运算。

04

聚合与结果

使用 count、first、aggregate 等操作消费结果，或转换为 List、数组和 Map。

01筛选偶数+

使用 Linq.ofInts 创建 Int 序列，通过 where 筛选偶数，并使用 toArray 获取结果。

Filtering.java
import io.github.piscescup.linq4j.Linq;
import java.util.Arrays;

public class Filtering {
    public static void main(String[] args) {
        var evens = Linq.ofInts(1, 2, 3, 4, 5)
            .where(value -> value % 2 == 0)
            .toArray();

        System.out.println(Arrays.toString(evens));
    }
}

运行结果

[2, 4]

03多级排序+

依次按 age 与 name 进行多级排序。Person 的 toString 方法保留 README 中的输出格式；示例省略了非必需的注解。

Ordering.java
import io.github.piscescup.linq4j.Linq;

public class Ordering {
    record Person(String name, int age) {
        @Override
        public String toString() {
            return name + "-" + age;
        }
    }

    public static void main(String[] args) {
        var people = Linq.of(
            new Person("Alice", 25),
            new Person("Bob", 20),
            new Person("Charlie", 25)
        );

        var ordered = people
            .orderBy(Person::age)
            .thenBy(Person::name)
            .toList();

        System.out.println(ordered);
    }
}

运行结果

[Bob-20, Alice-25, Charlie-25]

04数值聚合+

使用 IntEnumerable 的 sum 与 average 计算总和及平均值；示例将 README 输出标签中的 age 修正为 avg。

Aggregation.java
import io.github.piscescup.linq4j.core.IntEnumerable;

public class Aggregation {
    public static void main(String[] args) {
        int total = IntEnumerable.ofInts(1, 2, 3, 4, 5).sum();

        System.out.println("total = " + total + ", avg = " + avg);

05集合运算+

分别使用 distinct、except、intersect 和 union 获得去重、差集、交集与并集结果。

SetOperations.java
import io.github.piscescup.linq4j.Linq;

public class SetOperations {
    public static void main(String[] args) {
        var seq1 = Linq.of(1, 2, 3, 4);
        var seq2 = Linq.of(3, 4, 5, 6);

        var distinct = seq1.distinct().toList();
        var except = seq1.except(seq2).toList();
        var intersect = seq1.intersect(seq2).toList();
        var union = seq1.union(seq2).toList();

        System.out.println("distinct = " + distinct);
        System.out.println("except = " + except);
        System.out.println("intersect = " + intersect);
        System.out.println("union = " + union);
    }
}

运行结果

distinct = [1, 2, 3, 4]
except = [1, 2]
intersect = [3, 4]
union = [1, 2, 3, 4, 5, 6]

06组合查询：成绩筛选与排序+

基于 README 的 Student 示例，筛选成绩不低于 80 分的学生，按成绩降序排列，并提取姓名。

StudentQuery.java
import io.github.piscescup.linq4j.Linq;

public class StudentQuery {
    record Student(String name, int score) {}

    public static void main(String[] args) {
        var names = Linq.of(
                new Student("Alice", 92),
                new Student("Bob", 75),
                new Student("Charlie", 88)
            )
            .where(student -> student.score() >= 80)
            .orderByDescending(Student::score)
            .select(Student::name)
            .toList();

        System.out.println(names);
    }
}

运行结果

[Alice, Charlie]
