项目简介 主要功能 开始使用 命令示例

01 / OVERVIEW

项目简介

MC Wiki 使用 MediaWiki API 查找匹配条目，通过 MCEF Modern 在游戏内打开页面。模组仅需安装在客户端，可用于单人游戏和多人服务器。

02 / FEATURES

主要功能

01

分类搜索

按生物、方块、物品或结构等分类搜索，命令支持补全。

02

游戏内阅读

搜索结果直接在 MCEF Modern 浏览器界面中打开，无需切换窗口。

03

中英文 Wiki

通过命令切换 Wiki 语言，并在客户端配置中保存偏好。

03 / GET STARTED

开始使用

  1. 选择对应版本
    从下载页选择适合当前 Minecraft 版本的文件，并安装对应的 Fabric Loader。
  2. 安装模组与依赖
    将 MC Wiki、Fabric API 和 MCEF Modern 的对应版本 JAR 放入客户端 mods 文件夹。服务器无需安装。
  3. 启动并查询
    使用 Fabric 配置启动游戏，在聊天框输入下方命令即可搜索 Wiki。

MCEF Modern 首次初始化可能需要联网下载浏览器运行时，请等待下载与解压完成。

阅读完整使用说明

04 / COMMANDS

命令示例

查询生物与结构

/mc-wiki mobs pig
/wiki structures village

查看或切换 Wiki 语言

/mc-wiki settings lang get
/mc-wiki settings lang set en_us
/mc-wiki settings lang set zh_cn

en_us 对应英文 Wiki，zh_cn 对应中文 Wiki；所选语言也用于模组界面和命令反馈。
