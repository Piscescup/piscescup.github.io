01 / OVERVIEW

项目简介

PC Develop Lib V2 是一个面向 Minecraft Fabric 的开发基础库。它把内容注册、语言和标签数据生成组织成独立模块，方便在模组项目中复用。

02 / FEATURES

主要功能

01

内容注册

提供物品、方块、物品组、POI 与村民相关注册模块。

02

语言数据生成

数据生成入口演示了中文和英文语言工厂的配置。

03

标签数据生成

示例配置包含物品标签与 POI 类型标签。

03 / GET STARTED

开始使用

  1. 查看项目配置
    当前源码配置使用 Java 25、Minecraft 1.21.10 与 Fabric。开始前先查看仓库中的构建配置。
  2. 浏览注册示例
    从 register 模块和配套的 test 示例目录开始，了解注册模块如何组织。
  3. 了解数据生成
    阅读 PCDevelopLibDataGenerator.java 中的语言和标签配置，再结合示例了解具体用法。
