Minecraft 模组 · PC Develop Lib · V2

01 / OVERVIEW

项目简介

PC Develop Lib V2 是面向 Minecraft Fabric 的开发基础库，将内容注册、语言数据生成和标签数据生成封装为独立模块，便于在不同模组项目中复用。

02 / FEATURES

主要功能

01

内容注册

提供物品、方块、物品组、POI 与村民相关注册模块。

02

语言数据生成

数据生成入口提供中文与英文语言工厂的配置示例。

03

标签数据生成

示例配置包含物品标签与 POI 类型标签。

03 / GET STARTED

使用说明

  1. 01

    查看项目配置

    当前源码配置使用 Java 25、Minecraft 1.21.10 与 Fabric。使用前请先查看仓库构建配置，确认本地环境要求。

  2. 02

    浏览注册示例

    浏览 register 包及其配套的 test 示例，了解各类注册器的组织结构与调用方式。

  3. 03

    了解数据生成

    参考 PCDevelopLibDataGenerator.java 中的语言与标签配置，了解数据生成入口与扩展流程。
