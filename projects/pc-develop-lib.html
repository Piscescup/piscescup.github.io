01 / OVERVIEW

项目简介

PC Develop Lib V2 是面向 Minecraft Fabric 的开发基础库，将内容注册、语言数据生成和标签数据生成封装为独立模块，支持在模组项目中复用。

02 / FEATURES

主要功能

01

内容注册

提供物品、方块、物品组、POI 与村民相关注册模块。

02

语言数据生成

数据生成入口提供中文与英文语言工厂的配置示例。

03

标签数据生成

示例配置包含物品标签与 POI 类型标签。

03 / GET STARTED

开始使用

  1. 查看项目配置
    当前源码配置使用 Java 25、Minecraft 1.21.10 与 Fabric。使用前请查阅仓库中的构建配置，确认开发环境要求。
  2. 浏览注册示例
    查阅 register 模块及配套的 test 示例目录，了解注册模块的组织方式与使用方法。
  3. 了解数据生成
    查阅 PCDevelopLibDataGenerator.java 中的语言与标签配置，并参考配套示例了解数据生成流程。
