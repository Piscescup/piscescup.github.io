Minecraft 模组 · PCMC Develop Lib

01 / OVERVIEW

项目简介

PCMC Develop Lib（PiscesCup Minecraft Develop Library，模组命名空间为 pcmc-dev-lib）是面向 Fabric 模组的 Java 库，为内容注册以及相关的语言、标签、配方和村民交易数据生成提供链式 API。该库仍在积极开发中，首个稳定版本发布前，公共 API 可能发生变化。

02 / FEATURES

主要功能

01

内容注册

支持物品、方块及其方块物品、创造模式物品栏、兴趣点（POI）与村民职业。

02

数据生成

支持语言文件、各类注册表标签、有序与无序合成配方，以及按等级配置的村民交易。

03

统一的注册流程

各类注册器遵循相同的调用顺序：配置、register()、翻译与获取，便于记忆和复用。

03 / WORKFLOW

注册流程示例

FACTORY.path("entry_path")
    // Configure the entry here.
    .register()
    .translate(MCLanguage.EN_US, "Display Name")
    .get();

04 / GET STARTED

使用说明

  1. 01

    确认环境要求

    需要 Minecraft 26.2、Java 25 或更高版本，以及 Fabric Loader 0.19.5 或更高版本。

  2. 02

    创建注册工厂

    为每种内容类型和命名空间创建一个工厂，将条目声明为静态字段，并在模组初始化器中调用各声明类的 initialize() 方法。

  3. 03

    关注发布状态

    目前尚无稳定的公开版本，请通过 GitHub 仓库获取源码与最新进展。
