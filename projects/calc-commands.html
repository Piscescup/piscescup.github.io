Minecraft 模组 · Calc Commands

01 / OVERVIEW

项目简介

Calc Commands 是一个客户端模组，为 Minecraft 添加数学命令。它能保留分数和根式并给出小数近似，支持代数、微积分和复数，还可以把非负结果显示为潜影盒、组和剩余数量。单人游戏和多人服务器都能使用，无需服务端安装，也不需要管理员权限。

02 / FEATURES

主要功能

01

日常计算

统计材料数量、拆分堆叠、计算距离和换算角度，还可以用 ans 引用上一次的结果。

02

代数与微积分

支持解方程、展开、因式分解、化简、求导、积分和极限，开启复数模式后还能处理含 I 的运算。

03

聊天内辅助

命令带有 Tab 补全和函数提示，帮助页中的示例可以直接点击填入输入框。

03 / COMMANDS

命令示例

基础计算与代数

/calc expression 64*27
/calc solve x^2-5*x+6=0 x
/calc diff x^3 x --at x=2

按潜影盒与组显示数量

/calc numfmt enable
/calc expression 64*27+64+3

04 / GET STARTED

使用说明

  1. 01

    安装模组

    安装 Fabric Loader，并将 Calc Commands 与 Fabric API 放入客户端的 mods 文件夹，服务器无需安装。

  2. 02

    输入第一条命令

    在聊天栏输入上方的示例命令，例如 /calc expression 64*27。

  3. 03

    探索更多命令

    按 Tab 查看函数和选项，或使用 /calc help 打开对应命令的指南。
