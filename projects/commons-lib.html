01 / OVERVIEW

项目简介

Commons Lib 是一个面向 Java 21 的通用工具库，包含数据校验、常见数据结构及函数式编程工具。各模块围绕可复用、低耦合的日常开发组件组织，可以通过 Maven 添加到项目。

02 / FEATURES

主要功能

01

实用工具与校验

提供字符串、数组和比较工具，以及空值、参数与状态校验。

02

结构化数据

包含区间模型、Pair、固定长度元组，以及普通与原子计数器。

03

扩展函数接口

支持多参数、基本类型与可抛异常接口，并提供柯里化、部分应用和记忆化工具。

03 / GET STARTED

开始使用

  1. 准备 Java 21
    确认项目运行在 Java 21 或兼容的更新环境中。
  2. 添加 Maven 依赖
    将下方依赖添加到 pom.xml。版本 1.1.2 已在 Maven Central 发布。
  3. 从示例开始
    README 包含命名转换、区间、计数器、函数与 Pair 的快速示例。

Maven · pom.xml

<dependency>
    <groupId>io.github.piscescup</groupId>
    <artifactId>commons-lib</artifactId>
    <version>1.1.2</version>
</dependency>
