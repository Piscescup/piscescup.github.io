01 / OVERVIEW

项目简介

Commons Lib 是一个面向 Java 21 的通用工具库，包含数据校验、常见数据结构及函数式编程工具。各模块围绕可复用、低耦合的日常开发组件组织，可以通过 Maven 添加到项目。

02 / FEATURES

主要功能

01

实用工具与校验

提供字符串、数组和比较工具，以及空值、参数与状态校验。

02

结构化数据

包含区间模型、Pair、固定长度元组，以及普通与原子计数器。

03

扩展函数接口

支持多参数、基本类型与可抛异常接口，并提供柯里化、部分应用和记忆化工具。

01字符串命名转换+

使用 StringUtils 在 snake_case、UpperCamel 和 lowerCamel 命名形式之间转换。

StringNaming.java
import io.github.piscescup.util.StringUtils;

public class StringNaming {
    public static void main(String[] args) {
        String table = StringUtils.toSnakeLowerCase("HelloWorld");
        String clazz = StringUtils.toUpperCamel("player_inventory");
        String field = StringUtils.toLowerCamel("PLAYER_LEVEL");

        System.out.println(table);
        System.out.println(clazz);
        System.out.println(field);
    }
}

02区间边界检查+

使用 IntInterval 创建左闭右开的 [1, 10) 区间，并检查边界值与格式化结果。

IntervalChecks.java
import io.github.piscescup.interval.IntervalType;
import io.github.piscescup.interval.primitive.IntInterval;

public class IntervalChecks {
    public static void main(String[] args) {
        IntInterval range = IntInterval.of(1, 10, IntervalType.CLOSED_OPEN_INTERVAL);

        boolean containsOne = range.contains(1);
        boolean containsTen = range.contains(10);
        String display = range.formattedString();

        System.out.println(containsOne);
        System.out.println(containsTen);
        System.out.println(display);
    }
}

运行结果

false

03原子计数器+

通过 Counter.atomic 创建计数器，执行递增和累加后读取当前值。

Counters.java
import io.github.piscescup.counter.Counter;

public class Counters {
    public static void main(String[] args) {
        Counter counter = Counter.atomic();
        counter.increment();
        counter.addAndGet(4);

        long current = counter.get();
        System.out.println(current);
    }
}

04多参数函数与结果缓存+

使用 TriFunction 计算体积，演示完整调用、部分参数应用和 memorized 结果缓存。

ExtendedFunctions.java
import io.github.piscescup.interfaces.exfunction.TriFunction;

public class ExtendedFunctions {
    public static void main(String[] args) {
        TriFunction<Integer, Integer, Integer, Integer> volume =
            (x, y, z) -> x * y * z;

        int v1 = volume.apply(2, 3, 4);
        int v2 = volume.apply(2).apply(3, 4);

        TriFunction<Integer, Integer, Integer, Integer> cached = volume.memorized();
        int v3 = cached.apply(2, 3, 4);

        System.out.println(v1);
        System.out.println(v2);
        System.out.println(v3);
    }
}

运行结果

05Pair 映射+

使用 mappedLeft 转换 Pair 左侧的字符串，同时保留右侧的 Integer 值。

PairMapping.java
import io.github.piscescup.interfaces.Pair;

public class PairMapping {
    public static void main(String[] args) {
        Pair<String, Integer> pair = Pair.of("apple", 3);
        Pair<String, Integer> mapped = pair.mappedLeft(String::toUpperCase);

        String left = mapped.getLeft();
        Integer right = mapped.getRight();

        System.out.println(left);
        System.out.println(right);
    }
}

运行结果
