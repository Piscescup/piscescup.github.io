01 / OVERVIEW

Overview

PiscesCup Easy is a Fabric mod that simplifies Minecraft player management. It brings whitelists, operators, bans and language settings together under one command. The README recommends server-side use.

02 / FEATURES

Key features

01

Whitelist management

Add or remove whitelist entries by player name to manage server access.

02

Operators and bans

Manage operators and player-name bans through a consistent set of commands.

03

Language settings

Read the current language and switch command feedback between Chinese and English.

03 / GET STARTED

Get started

  1. Read the usage guide
    Review the README and command documentation, and check that the build matches your Minecraft version.
  2. Manage the whitelist
    With the required administrative permissions, use the command below and replace TestPlayer with the actual player name.
  3. Choose the message language
    Use the language-setting command to select zh_cn or en_us.

Commands from the README

/pc_easy whitelist add TestPlayer
/pc_easy setting lang set en_us
