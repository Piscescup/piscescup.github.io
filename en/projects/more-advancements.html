01 / OVERVIEW

Overview

More Advancements adds extra Minecraft advancements and playful objectives. From exploring dimensions to everyday activities, it offers more challenges to try, with text available in Chinese and English.

02 / FEATURES

Key features

01

Themed advancements

Generated advancement data is organized into adventure, End, husbandry, Minecraft and Nether categories.

02

Playful objectives

Existing objectives include collecting heads, observing mobs through a spyglass and eating a chorus fruit.

03

Chinese and English text

The repository includes zh_cn and en_us advancement titles and descriptions.

03 / GET STARTED

Get started

  1. Meet the project
    Read the README to learn about the project’s goal of adding advancement challenges.
  2. Explore the advancements
    Browse the generated advancement data alongside the language files to explore each objective’s title and description.
  3. Suggest an objective
    Have an idea for a new advancement? The README welcomes suggestions through GitHub Issues.
