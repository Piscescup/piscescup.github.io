01 / OVERVIEW

Overview

Commons Lib is a general-purpose Java 21 library with validation helpers, common data structures and functional-programming utilities. Its reusable, loosely coupled components can be added to your project through Maven.

02 / FEATURES

Key features

01

Utilities and validation

String, array and comparison helpers, plus null, argument and state validation.

02

Structured values

Intervals, pairs, fixed-arity tuples, and simple and atomic counters.

03

Extended functional interfaces

Multi-argument, primitive-specialized and throwable interfaces, with currying, partial application and memoization.

03 / GET STARTED

Get started

  1. Use Java 21
    Use Java 21 or a compatible newer environment for your project.
  2. Add the Maven dependency
    Add the dependency below to your pom.xml. Version 1.1.2 is published on Maven Central.
  3. Start with the examples
    The README includes quick examples for naming conversions, intervals, counters, functions and pairs.

Maven · pom.xml

<dependency>
    <groupId>io.github.piscescup</groupId>
    <artifactId>commons-lib</artifactId>
    <version>1.1.2</version>
</dependency>
