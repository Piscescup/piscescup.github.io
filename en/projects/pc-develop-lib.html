01 / OVERVIEW

Overview

PC Develop Lib V2 is a foundation for Minecraft Fabric development. It organizes content registration and language and tag data generation into modules that can be reused across mod projects.

02 / FEATURES

Key features

01

Content registration

Modules for registering items, blocks, item groups, points of interest and villagers.

02

Language data generation

The data-generation entry point demonstrates Chinese and English language factories.

03

Tag data generation

Example configurations cover item tags and point-of-interest type tags.

03 / GET STARTED

Get started

  1. Review the project setup
    The current source configuration uses Java 25, Minecraft 1.21.10 and Fabric. Review the repository’s build configuration first.
  2. Explore registration examples
    Start with the register module and the accompanying test examples to see how the registration modules fit together.
  3. Explore data generation
    Read the language and tag configuration in PCDevelopLibDataGenerator.java, then explore the accompanying examples.
